## ¿Qué ventaja concreta notaste al usar templates en tu clase Lista,comparado con haberla hecho solo para un tipo de dato (por ejemplo, solo enteros)? Da un ejemplo de tu propio código.
Con templates usé la misma clase List para guardar números y para guardar texto sin tener que agregar
mas lineas si la hubiera hecho solo para int  habría necesitado una clase aparte para string y asi 
por cada nuevo tipo de variable que quiera usar que a la larga puede hacer que compile mas lento.

## Qué parte de la actividad —ya sea el uso de templates o el reto de insertAt/removeAt— te costó más trabajo entender o depurar? ¿Qué hiciste para resolverlo?
Pues yo creo de lo que mas batalle fue con el pos, osea al inicio yo creia que era como T y hasta como string fijo hasta
que entendi que no se referia a un nuevo tipo de variable si no que era un int porque la posicion es siempre un numero,
tambien se me olvido como hacerle para bajar el size en removeLast pero no batalle tanto para encontrar como era.
